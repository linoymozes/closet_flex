Flexbox Quick Reference Guide

flex-direction

Defines the main axis along which flex items are placed (row or column).

justify-content

Aligns items along the main-axis and handles remaining free space.

align-items

Aligns items across the cross-axis (perpendicular to the main axis).

flex-wrap

Controls whether flex items are forced onto a single line or can wrap onto multiple lines.
